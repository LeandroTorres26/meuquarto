CategoryTag is a die-cut sticker that names a medium: Filme, Série, Anime, Mangá, Livro, Game or Música.

Provide the category (`mq-tag--movie|series|anime|manga|book|game|music`), its Lucide icon and the label in uppercase, plus an optional `mq-tag__count` for totals. Colors come from `sticker-*` and the white edge from `paper`; each category has a small built-in tilt that you can override with `--tilt`. Inside a media item it sits on the top-left corner and overlaps the edge; in a profile header it forms a row with counts.

Do: use one sticker per medium and keep the label to one word. Do not: make it round, use it for statuses or filters, or recolor it outside the `sticker-*` tokens.
