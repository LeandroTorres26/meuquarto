Button is the single action control, in four variants: `mq-btn--primary`, `mq-btn--secondary`, `mq-btn--ghost` and `mq-btn--danger`.

Provide a short imperative pt-BR label in sentence case ("Copiar link", "Sincronizar agora"). Use one primary button per view. Use `mq-btn--sm` inside cards and tables; the default size keeps a 44px touch target for mobile.

Do: show a disabled state with the reason in the label when a cooldown applies ("Aguarde 15 min"). Do not: use `accent` as a button fill, or color alone to signal danger; the label names the action ("Excluir conta").
